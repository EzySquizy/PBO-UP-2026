# AI Usage Documentation

## 1. AI Tool Used
- Tool: ChatGPT
- Provider: OpenAI
- Model: GPT-6

## 2. Purpose of AI Usage
AI digunakan sebagai alat bantu dalam memahami dan menyelesaikan praktikum P06 tentang pewarisan (inheritance) pada pemrograman berorientasi objek Python.

## 3. Areas Assisted by AI
AI membantu dalam:
1. Memahami konsep inheritance dan penggunaan `super()`.
2. Memahami implementasi class induk `AlatTani` dan class turunan `Traktor`, `PompaAir`, serta `Perontok`.
3. Memeriksa dan memperbaiki implementasi method `biaya_sewa()`.
4. Mengimplementasikan magic methods `__str__()`, `__repr__()`, `__eq__()`, dan `__hash__()`.
5. Menyusun pengujian otomatis menggunakan pytest.
6. Membantu memperbaiki peringatan Ruff dan masalah pemeriksaan tipe Mypy.
7. Memeriksa hasil pengujian dan menjalankan program utama.
