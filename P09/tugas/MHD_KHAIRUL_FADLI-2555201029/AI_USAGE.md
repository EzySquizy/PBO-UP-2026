# AI Usage – Praktikum P09

## 1. Tujuan Penggunaan AI

AI digunakan sebagai alat bantu pembelajaran selama pengerjaan praktikum P09 tentang Abstraksi, Abstract Base Class (ABC), Protocol, dan Enum pada Python.

## 2. Bentuk Penggunaan AI

AI digunakan untuk membantu:
1. Memahami konsep ABC dan metode abstrak.
2. Memahami perbedaan ABC dan Protocol.
3. Menerapkan Protocol pada kelas Sewaan dan GerobakDorong.
4. Mengimplementasikan Enum untuk status transaksi.
5. Menganalisis dan memperbaiki kesalahan kode Python.
6. Membantu menyusun dan mengevaluasi pengujian program.
7. Memeriksa hasil validasi menggunakan pytest, mypy, dan ruff.

## 3. Verifikasi

Hasil pemeriksaan akhir:
- Pytest: 155 pengujian berhasil.
- Mypy: 22 source files berhasil diperiksa.
- Ruff: seluruh pemeriksaan berhasil.
- Pemeriksa PBO profil P09: LOLOS.
- Program utama berhasil dijalankan.

## 4. Kesimpulan

AI digunakan sebagai alat bantu pembelajaran dan pengembangan program. Setiap saran kode diperiksa kembali melalui pembacaan kode, pelaksanaan program, dan pengujian agar hasilnya sesuai dengan ketentuan praktikum.
