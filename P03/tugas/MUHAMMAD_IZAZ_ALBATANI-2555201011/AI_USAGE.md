# AI Usage — P03

## 1. Teknologi AI yang Digunakan

Dalam menyelesaikan praktikum Pemrograman Berorientasi Objek (PBO) Pertemuan 3, saya menggunakan ChatGPT sebagai media pembelajaran untuk membantu memahami konsep enkapsulasi dan penerapannya dalam pemrograman Python.

## 2. Maksud Penggunaan AI

AI dimanfaatkan untuk membantu memahami cara melindungi atribut dalam sebuah kelas, menerapkan property getter dan setter, serta membuat validasi data agar nilai atribut sesuai dengan ketentuan yang telah ditentukan.

## 3. Kontribusi AI dalam Pengerjaan

Beberapa bentuk bantuan yang diperoleh dari ChatGPT selama praktikum, yaitu:

- Memberikan arahan dalam menyiapkan struktur folder dan file untuk proyek P03.
- Membantu memahami konsep enkapsulasi dan pembatasan akses terhadap atribut.
- Membantu menerapkan property pada kelas `AlatTani` dan `Penyewa`.
- Menjelaskan proses validasi tarif sewa, NIK, dan nomor telepon.
- Membantu memahami penggunaan `dataclass(frozen=True)` untuk membuat objek nilai `Alamat` yang tidak dapat diubah.
- Memberikan contoh penyusunan unit test menggunakan pytest, termasuk pengujian terhadap data yang tidak valid.
- Membimbing proses pemeriksaan program menggunakan pytest, mypy, dan checker PBO.
- Memberikan arahan dalam mengelola perubahan proyek menggunakan Git.

## 4. Hasil Pengujian Program

Setelah proses implementasi dan perbaikan kode selesai, dilakukan beberapa pengujian melalui terminal. Hasilnya menunjukkan bahwa 18 unit test berhasil dijalankan, pemeriksaan mypy tidak menemukan kesalahan tipe data, dan pemeriksaan disiplin PBO profil P03 dinyatakan lolos. Program utama juga berhasil dijalankan dan menampilkan informasi alat tani serta data penyewa dengan baik.
