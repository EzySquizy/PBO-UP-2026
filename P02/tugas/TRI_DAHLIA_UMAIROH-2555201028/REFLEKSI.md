# Refleksi Praktikum P02



Pada praktikum P02, saya mempelajari penerapan konsep Pemrograman Berorientasi Objek melalui pembuatan kelas Penyewa, AlatTani, dan Petugas.



Saya belajar menggunakan atribut, konstruktor, enkapsulasi, serta method untuk mengelola data dan perilaku objek.



Kendala yang saya hadapi adalah menyesuaikan program utama dengan kelas yang telah dibuat dan memastikan setiap fungsi berjalan sesuai kebutuhan. Saya mengatasinya dengan melakukan pengujian menggunakan pytest dan pemeriksaan tipe menggunakan mypy.



Dari praktikum ini, saya memahami bahwa pembagian program ke dalam beberapa kelas membuat kode lebih terstruktur, mudah diuji, dan lebih mudah dikembangkan.
